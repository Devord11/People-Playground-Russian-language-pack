# Сторонние компоненты

Готовый ZIP-архив из раздела Releases содержит **неизменённые** файлы следующих проектов:

| Компонент | Версия | Лицензия* | Источник |
|---|---|---|---|
| BepInEx | 5.4.23.6 | LGPL-2.1 | https://github.com/BepInEx/BepInEx |
| XUnity.AutoTranslator (+ ResourceRedirector) | 5.6.3.1 | MIT | https://github.com/bbepis/XUnity.AutoTranslator |

\* Лицензии указаны по состоянию на момент подготовки релиза. Актуальный текст
лицензий смотрите в репозиториях проектов, ссылки выше.

Контрольные суммы SHA-256 исходных архивов, из которых собирается релиз,
записаны в `tools/build_release.py`.

## Шрифт

Для отображения кириллицы используется готовый шрифтовой бандл
`arialuni_sdf_u2019` из релизов XUnity.AutoTranslator. Он основан на шрифте
Arial Unicode, лицензия которого может не разрешать перераспространение,
поэтому **в этом репозитории и в стандартном релизе бандла нет** — пользователь
скачивает его сам (см. README).
