# People Playground — русификатор

Неофициальный русский перевод интерфейса **People Playground** (Steam, Windows).
Проверялся на версии **1.28.37**.

> Проект не связан со Studio Minus и не одобрен ими.
> Работает через [BepInEx](https://github.com/BepInEx/BepInEx) и
> [XUnity.AutoTranslator](https://github.com/bbepis/XUnity.AutoTranslator): файлы игры не изменяются,
> перевод подставляется на лету. Интернет не используется.

## Установка

1. Откройте страницу **Releases** этого репозитория и скачайте `PeoplePlayground-RU-vX.Y.Z.zip`.
2. Распакуйте архив в любую папку.
3. Откройте папку с игрой: Steam → правый клик по **People Playground** → *Управление* → *Просмотреть локальные файлы*.
4. Скопируйте **всё содержимое** распакованного архива в эту папку (рядом с `People Playground.exe`). На вопрос о слиянии папок отвечайте «Да», на замену файлов — «Заменить».
5. **Установите шрифт** (см. ниже — это обязательно, иначе часть заглавных букв будет квадратиками).
6. Запустите игру через Steam как обычно.

### Шрифт (обязательный шаг)

В шрифте самой игры нет некоторых заглавных русских букв (А, Б, Г, Ж, З, Л и др.), поэтому нужен дополнительный шрифт.
Из-за лицензии на шрифт он не лежит в репозитории, его нужно скачать один раз:

1. Откройте [релизы XUnity.AutoTranslator](https://github.com/bbepis/XUnity.AutoTranslator/releases), найдите версию **5.5.0** и скачайте файл `TMP_Font_AssetBundles.zip` (он в списке *Assets*).
2. Из архива возьмите **один** файл — `arialuni_sdf_u2019` (без расширения).
3. Положите его в корень папки игры, рядом с `People Playground.exe`.

Если квадратики остались — замените его на `arialuni_sdf_u2021` и поменяйте имя в
`BepInEx\config\AutoTranslatorConfig.ini` (параметр `FallbackFontTextMeshPro`).

## Удаление

Удалите из папки игры: папку `BepInEx`, файлы `winhttp.dll`, `doorstop_config.ini`,
`.doorstop_version`, `changelog.txt` и файл шрифта `arialuni_sdf_u2019`.
Игра вернётся к оригинальному виду.

## Что внутри архива

| Файл | Откуда |
|---|---|
| `winhttp.dll`, `doorstop_config.ini`, `.doorstop_version`, `changelog.txt`, `BepInEx/core/*` | BepInEx 5.4.23.6, без изменений |
| `BepInEx/plugins/XUnity.*` | XUnity.AutoTranslator 5.6.3.1, без изменений |
| `BepInEx/config/AutoTranslatorConfig.ini` | настройки (`config/` в этом репозитории) |
| `BepInEx/Translation/ru/Text/main.txt` | сам перевод (`translation/` в этом репозитории) |

Контрольные суммы исходных архивов зашиты в `tools/build_release.py`. Архив можно собрать самостоятельно
(`python tools/build_release.py`) и сравнить с релизом — сборка проверяет SHA-256 скачанных файлов.

## Известные ограничения

- Тексты внутри чужих сохранений и модов (названия, надписи на предметах) не переводятся.
- В версии 1.28 разработчики отключили стандартные моды Мастерской; перевод работает независимо от них.
- Если игра обновится и добавит новый текст, он будет на английском, пока перевод не дополнят.
- Антивирус иногда ругается на `winhttp.dll` — это загрузчик BepInEx (ложное срабатывание типично для таких файлов).
- Проверено в основном на копии игры, запускаемой напрямую. Если в Steam-версии что-то не работает — создайте issue
  и приложите файл `BepInEx\LogOutput.log`.

## Как помочь с переводом

Строки лежат в `translation/main.txt`, формат: `English text=Русский текст`.

- Перенос строки в тексте записывается как `\n`, символ `=` внутри текста — как `\=`; теги вида `<b>…</b>` и метки `%F`, `%MB2` менять нельзя.
- Строки, начинающиеся с `r:`, — регулярные выражения для чисел с единицами измерения.
- Чтобы собрать новые строки, на тестовой копии игры временно поставьте в `AutoTranslatorConfig.ini`
  `Endpoint=GoogleTranslateV2` — найденные строки появятся в `BepInEx\Translation\ru\Text\_AutoGeneratedTranslations.txt`
  (при этом они отправляются в Google). Готовые правки вносите в `main.txt`, в игре `Alt+R` перезагружает перевод.
- Присылайте pull request или issue со скриншотом.
